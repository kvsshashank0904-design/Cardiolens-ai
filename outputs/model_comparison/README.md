## Model input contract and limitations

Input order: age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal. Before the saved pipeline, decode raw ca=4 and thal=0 to NaN exactly as in the runner's imported `matrix` helper. Other category codes remain the local CSV codes. The pipeline fills those missing entries with an explicit -1 category, scales numeric fields and one-hot encodes nominal fields using training-only state. Probability column for class 1 represents the corrected UCI presence coding; fixed threshold is 0.5.

No UI or deployment adapter is supplied. This is an educational comparison on a previously inspected holdout, with unknown patient independence and unresolved provenance details; it does not establish diagnostic ability or clinical validity.
